# كش مات — Chess Portal

نسخة واجهة ثابتة باللغة العربية واتجاه RTL، منشورة باستخدام GitHub Pages.

## ماذا تتضمن؟

- **نظرة عامة:** تعريف مؤقت بالمنصة وبطاقة جدول بطولة العالم.
- **التصنيفات:** لقطة FIDE المفتوحة لشهر نوفمبر 2026 (أول 10 لاعبين).
- **آخر الأخبار:** خبرين موجزين مع روابط إلى المصدر الرسمي.
- **إدارة الموقع:** نموذج استعراضي غير متصل بخادم. تسجيل الدخول وإضافة الخبر لا يعملان ولا يحفظان أي بيانات.

## قيود النسخة الثابتة

لا يوجد خادم PHP/Laravel في هذا النشر، ولا قاعدة بيانات، أو مصادقة حقيقية، أو تحديث آلي للترتيب أو الأخبار أو جدول المباريات. الترتيب والأخبار والمواعيد محتوى ثابت مؤرخ، وقد يصبح قديماً. صفحة الإدارة للتصميم والمعاينة فقط.

## النشر

المحتوى المنشور في `public-site/`. سير عمل GitHub Actions في `.github/workflows/pages.yml` ينشر المجلد إلى GitHub Pages بعد كل دفع إلى `main`.
